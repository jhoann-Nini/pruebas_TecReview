## Cómo guardar evidencia

1. Guardar la captura o salida en una carpeta de evidencias del Sprint.
2. Comprobar que se vean el contexto y el resultado relevante.
3. Ocultar datos sensibles antes de guardar o compartir.
4. Registrar aquí el enlace o nombre exacto del archivo y su fecha.
5. En Jira, enlazar el ID de evidencia en la tarea correspondiente.

No subir volcados completos de logs ni exportaciones de usuarios. Conservar solo el fragmento mínimo necesario para demostrar el resultado.
